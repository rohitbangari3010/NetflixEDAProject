# NetflixEDAProject

## Overview

This project performs an exploratory data analysis(EDA) of the netflx movies and tv shows
It includes data cleaning, visualization, text analysis and insights about netflix's content strategy

## Key Skills Demonstrated

- Data cleaning(tidyverse, janitor)
- visualization
- text mining
- working with dates (lubridate)
- insight generation

## Main Insights
- Netflix has more movies than TV shows
- Top genres : Dramas, Comedies, Documentaries
- Most content is rated TV-MA or TV-14
- Massive growth from 2015-2020
- USA, India, UK, Japan and South Korea dominate content production
- Text analysis shows common themes: love,family,life,young,murder

## Dataset
Kaggle: Netflix Movies and Tv shows
